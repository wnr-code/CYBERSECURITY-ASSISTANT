# CYBERSECURITY-ASSISTANT

AI-powered, local-first Android cybersecurity platform built around a user-controlled tool ecosystem and optional user-owned cloud services.

See the [Final Technical Blueprint](docs/technical-blueprint.md) for the architecture, security principles, integrations, and development roadmap; the [static security audit](docs/security-audit.md) records current findings and verification blockers. The initial Flutter UI foundation is in [`apps/android`](apps/android/README.md).
